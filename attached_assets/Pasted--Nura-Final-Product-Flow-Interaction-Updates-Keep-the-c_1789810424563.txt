# Nura — Final Product Flow & Interaction Updates

Keep the **current Nura design system and visual style**. Do not redesign the application.

The goal is to simplify the information architecture and make the existing prototype interactions actually work.

Keep the current:

* Nura branding
* Blue/white visual system
* Typography
* Cards
* Bottom navigation
* Mobile-first iPhone layout
* Existing AI concept/architecture

Do not remove the AI capability from the product. For now, focus on making the current core product flow functional and connected.

---

# 1. HOME SCREEN — SIMPLIFY IT

Remove the **pencil icon** from the "What happened?" section.

The "What happened?" section should remain a primary action, but it should not have a pencil/edit icon.

Use:

## What happened?

Save a visit, question, report, or small health update while it's fresh.

[ + Add health memory ]

The button should be the only primary action.

---

# 2. REMOVE THE LARGE FAMILY MEMBER LIST FROM HOME

Do NOT show a long list of family members directly on the Home screen.

Instead, combine:

**Family + Memories**

into one meaningful section.

Use something like:

## Your family

See what each person has going on.

Then show compact family memory cards.

Example:

### Bhuvaneswari

2 health memories
1 upcoming reminder

[ View ]

### Meera

4 health memories
2 upcoming reminders

[ View ]

### Arjun

1 health memory
No upcoming reminders

[ View ]

The number of memories should be dynamic based on the actual data.

Do not duplicate the same family information in multiple sections.
