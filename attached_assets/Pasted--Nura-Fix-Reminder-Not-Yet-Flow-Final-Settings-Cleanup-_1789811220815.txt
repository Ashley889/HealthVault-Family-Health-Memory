# 8. REMINDER STATUS SYSTEM

Make sure every reminder supports these states:

### Upcoming

The reminder date is in the future.

### Due

The reminder date has arrived and the user has not confirmed what happened.

### Completed

The user selected "Yes, I went" and saved the health event.

### Rescheduled

The user moved the reminder to another date.

### Missed

The user explicitly marked it as missed.

Never automatically mark a reminder as Completed.
