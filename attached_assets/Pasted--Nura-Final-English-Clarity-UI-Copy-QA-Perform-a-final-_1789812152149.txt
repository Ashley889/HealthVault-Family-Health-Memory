# Nura — Final English, Clarity & UI Copy QA

Perform a final **English language and content-quality review across the entire Nura mobile application**.

Do not redesign the application.

Do not change the existing functionality that is already working.

Do not change the current Nura visual design system.

This is a final **English, wording, clarity, consistency, and usability pass**.

---

# 1. REMOVE PROFILE PENCIL ICON

On the Profile / Settings screen, remove the pencil/edit icon completely.

The profile card should simply show:

**Bhuvaneswari**

Family organizer

No pencil icon.

Do not provide editing through this card.

Account information can continue to be edited through:

**Settings → Account information**

---

# 2. REVIEW ALL ENGLISH IN THE APPLICATION

Go through **every screen, button, label, heading, description, form, error message, confirmation message, empty state, reminder, notification setting, and navigation item**.

Check whether the English is:

* Grammatically correct
* Natural
* Clear
* Easy to understand
* Consistent
* Short enough for mobile
* Appropriate for a general audience
* Friendly but professional
* Free from unnecessary technical terminology

Use simple, everyday English.

The user should understand what to do without needing an explanation.

---

# 22. CONSISTENCY CHECK

Make sure the same concept always uses the same wording.

For example, use only:

**Health memory**

Do not randomly switch between:

Health memory
Health note
Health update
Medical memory
Health record

Use:

**Reminder**

instead of switching between:

Reminder
Task
Appointment task
Follow-up task

Use:

**History**

instead of switching between:

History
Records
Medical records
Timeline

Where the UI is specifically about a person's chronological events, "History" is the preferred label.

---

Sep 25 2026

Choose one clear format and use it consistently.

**Create reminder**

**Notifications & reminder preferences**

Keep NURA branding as:

**NURA**

---

# 25. FINAL ENGLISH QA

Read every screen as if the user has never seen Nura before.

Ask:

"Would a normal person immediately understand what this means?"

If not, simplify the wording.

Avoid:

* Corporate language
* Technical jargon
* AI terminology where unnecessary
* Long sentences
* Repeated explanations
* Confusing medical terminology
* Grammar mistakes
* Awkward Indian-English phrasing
* Duplicate statements

Use natural, modern, simple English.
