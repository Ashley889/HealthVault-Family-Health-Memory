# Nura — Reminder, Notification & Health History Flow

Continue using the **existing Nura mobile app design system**.

Do not redesign the UI from scratch.

Keep:

* Nura branding
* Soft blue + white color palette
* Dark navy typography
* Rounded cards
* Existing bottom navigation
* Existing Home, History, Reminders and Profile structure
* Existing iPhone/mobile-first layout

The goal is to make the **notification settings and reminder workflow functional and connected to Health History**.

---

## 1. Notification Settings

The current notification preference/reference is not working.

Add a proper notification setting inside:

**Profile → Settings → Notifications & Reminder Preferences**

Create a functional screen:

### Notifications

**Health reminders**

Get notified about upcoming appointments, tests and follow-ups.

[ ON / OFF ]

When enabled:

* Show reminder notifications for upcoming health events.
* Allow reminder-related notifications to be triggered.

When disabled:

* Do not send reminder notifications.
* Existing reminders should still remain visible inside the Reminders tab.

The toggle must actually work.

### Reminder notification timing

When notifications are ON, allow:

* 1 day before
* On the day
* Both

Example:

**Annual health check**

Reminder:
Aug 13, 2027 — 9:00 AM

Appointment:
Aug 14, 2027

Do not create unnecessary notification settings. Keep this simple.

[ No, not yet ]

# 10. Save Health Event

At the bottom:

**[ Save to health history ]**

When clicked:

1. Save the health event.
2. Mark the original reminder as **Completed**.
3. Add the event to the person's History.
4. Associate medications with the event.
5. Associate tests with the event.
6. Associate uploaded reports with the event.
7. Create any follow-up reminder.
8. Return the user to the Reminders screen.

Show confirmation:

### Saved to health history

"Your visit and its details are now part of Aditi's health history."

[ View history ]

# 18. Mobile / iPhone Requirements

This must remain a **real mobile-first iPhone experience**.

Do not design fixed-size web layouts.

All screens must:

* Fit within the iPhone safe area.
* Respect the Dynamic Island.
* Respect the bottom Home Indicator.
* Scroll vertically when content is long.
* Never clip text.
* Never hide buttons.
* Never hide medication information.
* Never hide uploaded reports.
* Never allow content to disappear underneath the bottom navigation.

Cards must use **auto height**.

Long content should make the card taller rather than cutting content.

---
