# 18. DO NOT FAKE STATUS

Do not simply change the text shown on screen.

The actual reminder object/state must change.

For example, do not do:

```text
statusLabel = "Missed"
```

while the stored reminder remains Due.

Instead update the actual reminder state:

```text
reminder.status = "missed"
```

and render the UI from that state.

The same principle applies to:

completed

rescheduled

due

upcoming
